# Rapido Fast Auto Clicker (100% Free Open Source)

வீடியோ பார்த்துக் கொண்டிருக்கும் போதும், வாட்ஸ்அப்பில் இருக்கும் போதும் Rapido கேப்டன் ஆப்பில் ஆர்டர் வந்த உடனே 0.1 நொடியில் தானாக கிளிக் / ஸ்வைப் செய்து ஏற்கும் எளிய ஆப்.

## சிறப்பம்சங்கள்:
1. **எந்த கட்டணமும் இல்லை (100% Free Open Source)**
2. **நேரடி மாஸ்டர் ஆன்/ஆஃப் சுவிட்ச் (Master ON/OFF Switch)**: ஆன் செய்தால் போதும், எந்த ஆர்டர் வந்தாலும் உடனே ஏற்கும்!
3. **மிதக்கும் சுவிட்ச் (Floating Switch)**: யூடியூப் அல்லது வீடியோவின் மேல் மிதந்து கொண்டிருக்கும், அங்கேயே தொட்டு ஆன்/ஆஃப் செய்து கொள்ளலாம்.
4. **ஸ்வைப் & டேப் ஜெஸ்ச்சர் (Swipe & Tap Support)**: ராபிடோவின் "Swipe to accept" ஸ்லைடராக இருந்தாலும் அல்லது "Tap" பட்டனாக இருந்தாலும் நொடியில் ஏற்கும்.
5. **பேட்டரி சேவர் விலக்கு (Battery Optimization Exemption)**: போன் லாக் அல்லது பேக்ரவுண்டில் இருக்கும் போதும் ஆப் தூங்காமல் வேலை செய்யும்.
